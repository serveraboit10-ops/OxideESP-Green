# Oxide ESP — Green Demo

Android Studio project with a black/neon-green interface, ESP-style boxes around **synthetic demo targets**, distance labels, and color cycling.

**Important:** this is a standalone visual demo. It does not connect to Oxide 1.17.11995, inspect game memory, or reveal real players/objects.

## Build an APK
1. Install Android Studio.
2. Open this folder as a project.
3. Let Gradle sync and install Android SDK 35 if prompted.
4. Select **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Find the APK at `app/build/outputs/apk/debug/app-debug.apk`.

Application ID: `com.example.oxideespgreen`
Minimum Android: 6.0 (API 23).
